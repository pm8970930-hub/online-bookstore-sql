# 📚 Online Bookstore SQL Project

## 📌 Project Overview
This is my first SQL project, focused on analyzing an online bookstore database using PostgreSQL. The project explores book details, customer information, and order records to practice SQL querying and derive meaningful insights from data.

## 🎯 Project Objectives
- Analyze bookstore data using SQL queries.
- Explore customer orders and book information.
- Retrieve meaningful insights using data filtering and aggregation.
- Understand relationships between multiple tables.
- Strengthen foundational SQL and database management skills.

## 🛠️ Tools Used
- **Database:** PostgreSQL
- **Query Language:** SQL
- **Environment:** SQL editor / PostgreSQL client

## 🗂️ Database Tables
The project consists of three tables:

1. **Books:** Contains information about books.
2. **Customers:** Contains customer information.
3. **Orders:** Contains order-related information.

These tables are connected through JOIN operations to analyze related data.

## 💡 SQL Concepts Practiced
- SELECT statements and data retrieval
- WHERE clauses and filtering
- Aggregate functions
- GROUP BY and ORDER BY
- JOIN operations
- Subqueries
- Data analysis using SQL

## 📈 Key Learning Outcomes
Through this project, I gained practical experience in querying relational databases, combining data from multiple tables, and analyzing bookstore information using SQL.

This project marks the beginning of my journey into SQL, database management, and data analytics.
